# Contributing to agent-framework

Thanks for helping improve the framework. This document covers local setup,
tests, style, and commit conventions.

## Development setup

```bash
git clone <repository-url> agent-framework
cd agent-framework
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev,sqlite]"
```

The `dev` extra pulls in pytest, pytest-asyncio, ruff, httpx, aiosqlite, and
jinja2 — everything needed to run the suite and the examples.

## Running tests

```bash
pytest                     # full suite
pytest -v                  # verbose
pytest -k "memory"         # filter by name
```

Tests use `asyncio_mode = "auto"` (configured in `pyproject.toml`), so async
test functions need no decorator.

## Linting & formatting

We use [ruff](https://docs.astral.sh/ruff/) for both linting and formatting
(config in `pyproject.toml`: `target-version = py311`, `line-length = 100`):

```bash
ruff check src/ tests/     # lint
ruff format src/ tests/    # format
```

Both `ruff check` and `pytest` must pass before a change is merged.

## Commit conventions

Follow [Conventional Commits](https://www.conventionalcommits.org/):

```
<type>: <description>

<optional body>
```

Types: `feat`, `fix`, `refactor`, `docs`, `test`, `chore`, `perf`, `ci`.

**Commits must not include AI/assistant co-author attribution.** Do not add
`Co-authored-by` trailers or "generated by" lines for AI assistants; commits are
authored by the human making the change.

## Making changes

1. Create a branch from `main`.
2. Make your changes and add or update tests in `tests/`.
3. Run `ruff check` and `pytest` — both must pass.
4. Open a pull request describing the change and its rationale.

## Adding a persistence backend

1. Create `src/fg_agents/persistence/mybackend.py`.
2. Implement every method of `BaseRepository` (see `persistence/base.py`).
3. Register it in `persistence/factory.py`.
4. Export it from `persistence/__init__.py`.
5. Add tests in `tests/test_persistence.py`.

## Adding an LLM provider

1. Add the streaming and completion paths in `core/llm.py`.
2. Add message/tool format converters for the provider.
3. Wire it into client initialization (`_get_client()`).
4. Add the optional dependency in `pyproject.toml`.
